Доорх хүснэгтийг хэрхэн тооцсон
Аль аргыг ашиглахаа эцэслэн шийдээгүй тул хоёр аргаар зэрэг тооцоолж харуулж байна. Одоогоор үндсэн (дундаж-суурьт) арга хэрэглэгдэж байгаа бөгөөд шинэ (A/B харьцаат) арга нь зөвхөн харьцуулах баганад харагдана.

Сургууль тус бүрийн Нийт квот = Сургуулиас (суурь эрх) + Жагсаалтаар (нэмэлт эрх). Хоёр хэсгийг доор тус тусад нь тайлбарлав.

1. "Сургуулиас" (суурь эрх) — багана: Сургуулиас (суурь)

Аймаг/дүүргийн бүх сургууль ангилал тус бүрд тогтмол {{ qt.base_quota_per_school }} сурагчийн ({{ qt.region_type }}) суурь эрхтэй байна — энэ жилийн I давааны бодит дүнгээс үл хамааран (I даваа хараахан болоогүй ч энэ эрх баталгаатай).

2. "Жагсаалтаар" (нэмэлт эрх, үндсэн арга) — багана: {{ qt.year_names.0 }} / {{ qt.year_names.1 }} / {{ qt.year_names.2 }} / Жагсаалтаар (нэмэлт)

2-р давааны олимпиадад сүүлийн 3 жилийн ({{ qt.year_names.0 }}, {{ qt.year_names.1 }}, {{ qt.year_names.2 }}) тус бүрд, тухайн сургуулиас хэдэн сурагч Top {{ qt.historical_topn }} ({{ qt.region_type }}) байранд орсоныг тоолж, 3 жилийн баганад тус тусад нь харуулав. Оноо тэнцсэн тохиолдолд аль цөөнийг сонгоно.

Жагсаалтаар (нэмэлт) = ceil(дундаж(3 жилийн тоо)) — 3 жилийн тоог дундажлаад дээш нь бүхэлчилсэн дүн. Дүн ороогүй/олимпиад явагдаагүй жилийг 0 гэж тооцно.

Хүснэгтийн баруун талд саарал өнгөөр "Шинэ арга (A/B) — харьцуулах" баганууд харагдана. Энд A = тухайн сургуулиас 3 жилд Top {{ qt.historical_topn }}-д орсон нийт тоо, B = {{ qt.province.name }} даяар (бүх сургуулийн) 3 жилийн нийт тоо (одоо B = {{ qt.total_B }}), Нэмэлт = ceil((A/B) × {{ qt.historical_topn }}). Энд тэнцлийг ranking_b_p талбараар тооцно (тэнцсэн бүлэг хамгийн муу байраар тэмдэглэгддэг тул "тэнцвэл цөөнийг сонгоно" дүрмийг хэрэгжүүлдэг).
