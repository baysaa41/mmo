Дүүрэг тус бүрийн Нийт квот = Дүүргээс (суурь эрх) + Жагсаалтаар (нэмэлт эрх).

1. "Дүүргээс" (суурь эрх)

Нийслэлийн бүх дүүрэг ангилал тус бүрд тогтмол {{ qt.base_quota_per_district }} {% if qt.is_teacher_category %}багшийн{% else %}сурагчийн{% endif %} суурь эрхтэй байна — энэ жилийн аймаг/дүүргийн олимпиадын бодит дүнгээс үл хамааран баталгаатай эрх.

2. "Жагсаалтаар" (нэмэлт эрх) — багана: {{ qt.year_names.0 }} / {{ qt.year_names.1 }} / {{ qt.year_names.2 }} / Жагсаалтаар
{% if qt.is_teacher_category %}

Нийслэлийн round=3 олимпиадад сүүлийн 3 жилийн ({{ qt.year_names.0 }}, {{ qt.year_names.1 }}, {{ qt.year_names.2 }}) тус бүрд, тухайн дүүргээс хэдэн багш хот даяар Top {{ qt.historical_topn }}-д орсоныг тоолж, 3 жилийн баганад тус тусад нь харуулав.

Багшийн ангилалд нийт {{ qt.teacher_total_quota }} нэмэлт эрхийг дүүргүүдэд A/B харьцаагаар хуваарилна: A(дүүрэг) = тухайн дүүргээс 3 жилд Top {{ qt.historical_topn }}-д орсон нийт тоо, B = нийслэл даяар 3 жилийн нийт тоо (одоо B = {{ qt.total_B }}), Нэмэлт(дүүрэг) = ceil((A/B) × {{ qt.teacher_total_quota }}).

{% else %}

Нийслэлийн round=3 олимпиадад сүүлийн 3 жилийн ({{ qt.year_names.0 }}, {{ qt.year_names.1 }}, {{ qt.year_names.2 }}) тус бүрд, тухайн дүүргээс хэдэн сурагч хот даяар Top {{ qt.historical_topn }}-д орсоныг тоолж, 3 жилийн баганад тус тусад нь харуулав. Оноо тэнцсэн тохиолдолд аль цөөнийг сонгоно.

Жагсаалтаар (нэмэлт) = ceil(дундаж(3 жилийн тоо)) — 3 жилийн тоог дундажлаад дээш нь бүхэлчилсэн дүн. Дүн ороогүй/олимпиад явагдаагүй жилийг 0 гэж тооцно. Дүүрэг тус бүр тусад нь тооцогдох тул нийлбэрт хязгаар байхгүй.

{% endif %}

"Нийслэл" олимпиадын гишүүнчлэл өөрөө "жинхэнэ УБ хотын сурагч" гэсэн үг биш (зөвхөн улсын квотод өрсөлдөхөөр ирсэн бусад аймгийн сурагч ч тэнд бүртгэлтэй байж болно). Тиймээс round=3-ийн БҮХ олимпиадын ("нийслэл" ба "бүс", хуучин жилүүдэд ганц хосолсон бол түүнийг) дүнг нэгтгээд, аль хэдийн тооцогдсон ranking_b_z (zone_id=5, "жинхэнэ" 7 дүүргийн сурагчдад зориулж тухайн олимпиад бүрд тусад нь тооцогддог) талбараар шүүнэ. Тэнцсэн бүлэг хамгийн муу байраар тэмдэглэгддэг тул "тэнцвэл цөөнийг сонгоно" дүрмийг байгалиараа хэрэгжүүлдэг. Нэг сурагч хоёр round=3 олимпиадад зэрэг бүртгэлтэй байдаггүй тул нэгтгэхэд давхардал үүсэхгүй.
